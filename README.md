## 🙋‍♂️ About Me

> **"구조화된 지식과 다단계 추론으로 신뢰성 있는 AI 시스템을 구축합니다."**

LangChain, LangGraph, RAG, 그리고 Graph RAG를 중심으로, 구조화된 지식과 다단계 추론이 어떻게 신뢰성, 검색 품질, 자동화를 향상시킬 수 있는지 탐구하고 있습니다.

현재는 **에이전트 개발자(Agent Developer)** 로 성장하며, LLM과 지식 그래프, 오케스트레이션 프레임워크, 근거 기반 추론을 결합해 복잡한 실제 문제를 해결하는 시스템을 설계하고 있습니다.

**💡 핵심 관심 분야**
- **Architecture**: Agentic AI 시스템, 멀티 에이전트 오케스트레이션
- **Frameworks**: LangChain, LangGraph
- **Knowledge**: RAG & Graph RAG, 지식 그래프 기반 추론
- **Operations**: 검색, 평가, 자동화 워크플로우
